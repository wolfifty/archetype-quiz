# Тест на архетип — Telegram Mini App

Простой квиз на 5 вопросов, 4 варианта ответа, в конце — один из 4 архетипов
(Звезда / Эксперт / Блогер / Серый кардинал) с готовой картинкой-результатом.

Стек: React + Vite, без бэкенда (весь тест зашит в статике).

## Структура проекта

```
archetype-quiz/
├── public/images/       ← картинки (фон теста + 4 результата)
├── src/
│   ├── quizData.js      ← вопросы, варианты, тексты — редактируется без знания кода
│   ├── App.jsx          ← вся логика квиза
│   ├── index.css        ← стили
│   └── main.jsx
├── index.html
├── package.json
└── vite.config.js
```

## 1. Установка и локальный запуск

Понадобится Node.js версии 18+ (скачать: https://nodejs.org, если ещё не стоит).

```bash
# распакуй архив / склонируй репозиторий, перейди в папку проекта
cd archetype-quiz

# установи зависимости
npm install

# запусти локальный сервер разработки
npm run dev
```

Терминал покажет ссылку вида `http://localhost:5173` — открой её в браузере,
пройди тест, проверь что всё работает: вопросы листаются, кнопка "назад"
работает, в конце показывается правильная картинка результата.

## 2. Заливаем на GitHub

```bash
git init
git add .
git commit -m "Первая версия теста на архетип"
```

Дальше создай пустой репозиторий на github.com (без README/gitignore при
создании — они уже есть) и выполни команды, которые GitHub покажет на
странице нового репозитория (что-то вроде):

```bash
git remote add origin https://github.com/ТВОЙ_НИК/archetype-quiz.git
git branch -M main
git push -u origin main
```

## 3. Деплой на Vercel

1. Зайди на https://vercel.com, залогинься через GitHub
2. "Add New" → "Project" → выбери репозиторий `archetype-quiz`
3. Vercel сам определит, что это Vite-проект (framework preset: Vite) —
   ничего менять не нужно, жми "Deploy"
4. Через минуту получишь ссылку вида `archetype-quiz-xxxx.vercel.app` —
   это и есть рабочий адрес твоего теста

При каждом `git push` в `main` Vercel будет пересобирать и обновлять сайт
автоматически.

## 4. Подключаем как Telegram Mini App

1. Открой @BotFather в Telegram
2. Если бота ещё нет — `/newbot`, если есть — просто дальше
3. `/newapp`, выбери своего бота, укажи название и картинку
4. В качестве Web App URL укажи ссылку с Vercel (шаг 3)
5. BotFather даст ссылку вида `t.me/ТВОЙ_БОТ/ИМЯ_ПРИЛОЖЕНИЯ` — открой её
   в Telegram (с телефона лучше всего) и проверь, что тест открывается
   и работает внутри самого Telegram, а не только в браузере

## Как редактировать вопросы/архетипы

Всё содержимое теста — в `src/quizData.js`. Там два блока:

- `questions` — массив из 5 вопросов, у каждого 4 варианта. У каждого
  варианта есть `archetype` — на какой архетип идёт "голос" при выборе
  этого варианта (`star`, `expert`, `blogger`, `eminence`)
- `results` — какая картинка показывается для какого архетипа

Поменять текст вопроса, порядок вариантов или картинку результата можно
прямо здесь, без изменения остального кода.
